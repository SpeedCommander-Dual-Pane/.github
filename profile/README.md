# SpeedCommander

> One named SpeedCommander pair. Finish the compare. Leave a note the next move can read.

## Session Card

| Slice | What you do in SpeedCommander | What remains |
|-------|------------------------|--------------|
| Arrival | Open SpeedCommander and name today's file desk | A titled dual pane |
| Pane | Keep only live folders on the SpeedCommander board | A short tab list |
| Compare | Read SpeedCommander folder compare before a move | A confirmed pair |
| Handoff | Mark finished compares inside SpeedCommander | A note for the next visit |

## How SpeedCommander Sits

SpeedCommander does not replace the editor, the backup tool, or the drives you already use. It sits beside them as a named file desk for one job: which dual pane is live, which file tabs still match the folder compare, and what the next person should read before the next move.

If two people share a file PC, each keeps a SpeedCommander style of their own. Extra folders wait for their own title instead of crowding the live panes.

A first visit should be one short compare, then the same SpeedCommander file desk the next day. That is enough to see if the dual pane holds.

## Traffic Light

| Signal | On the SpeedCommander board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live tab list | Continue the same dual pane |
| Amber | Two jobs mixed in one folder compare | Split the pair before a move |
| Red | No title, no note, tabs unlabeled | Stop and name the desk first |
| Clear | Handoff written, live tabs few | Close SpeedCommander and leave the desk |

## Open Order

1. Open the last SpeedCommander file desk, not a new empty dual pane.
2. Read the file tabs and the last handoff.
3. Finish one visible folder compare inside SpeedCommander.
4. Write what changed, then close with fewer unlabeled tabs than you found.
5. If the pair feels crowded, drop anything that belongs to a different SpeedCommander job.
6. Confirm SpeedCommander dual pane still shows both folders you own.
7. Leave the file desk title on the board before you close.

## Desk Fit

| Who | What SpeedCommander holds |
|-----|--------------------|
| File desk | Dual pane, file tabs, and the compare you run |
| Shared desk | One SpeedCommander profile per person |
| Move night | Named pairs waiting for the next compare |
| Support | A repeatable SpeedCommander layout for the same tabs |
| Home folders | Personal files out of the work pair |
| Client packet | Drafts kept apart from delivery folders |

## After a Week

A week in SpeedCommander is not a larger unlabeled tab pile. It is the same title, a shorter live dual pane, and a note that still makes sense before the next move. Take finished compares off the live set so the next visit starts on the pair that is still open.

Other programs stay where they are. SpeedCommander only keeps the path back: desk name, dual pane, file tabs, handoff.

Leave SpeedCommander with a quieter file desk than the one you opened. The next visit should start on that compare, not in a single Explorer window.

## Sign-off

- [ ] The SpeedCommander workspace name is short enough to scan
- [ ] Only live folders sit in the panes
- [ ] A second person can read the compare handoff
- [ ] The last SpeedCommander desk still opens after a restart
- [ ] Finished compares are off the live SpeedCommander set
- [ ] The SpeedCommander summary still matches the file tabs

## Field Note

SpeedCommander is easier to trust when the file desk stays smaller than the folder pile it came from. Name the pair, keep the live tabs, finish one visible compare, and write what changed.
